# 米雇用統計イベントの実証検証

米雇用統計（Employment Situation）発表前後の値動きを、2013〜2026年の計159回について集計した実証記録です。
**2020〜2026年で調整した条件を、未使用の2013〜2019年へそのまま当てたところ再現しませんでした。**
その過程と、イベント検証で過剰適合を避けるための手順をまとめています。

公開サイト: https://naporit0742.github.io/nfp-event-study/

## これは投資助言ではありません

本サイトは過去データの統計分析と方法論の解説です。
特定の金融商品の売買を推奨せず、将来の値動きや成果を示唆するものでもありません。
掲載した集計結果は、対象期間・標本数・入力データの品質・除外条件に依存します。

## データの境界

**元データは含めていません。** 公開しているのは集計値・図表・方法論・作図コードだけです。

| データ | 出所 | 再配布 |
|---|---|---|
| 実績値 | BLS Employment Situation | 米国政府著作物 |
| 市場予想 | 個人ブログ、みんかぶFX | 許諾を確認できないため非掲載 |
| 価格 | HistData.com | 許諾を確認できないため非掲載 |

個別イベントの日付・価格系列・市場予想値は掲載していません。
図は多数イベントを平均・集計したもので、個別の値は復元できません。

## ローカルでの表示

```
python -m http.server 8000
```

ビルド、npm、外部CDNは不要です。外部への通信も行いません。

## 図の作図

```
python reproduce/generate_figures.py
```

このスクリプトは元データを読みません。読めるようにもしていません（上記のとおり再配布できないため）。
含まれるのは元調査で算出済みの集計値だけです。信頼区間だけは、平均値・t値・件数から
スクリプト内で導出しています（ブートストラップではなく t 分布に基づく区間です）。
日本語表示には Yu Gothic、Meiryo、MS Gothic、Noto Sans CJK JP のいずれかが必要です。

## 公開前の自己検証

```
python reproduce/verify_site.py
```

必須ファイル、JSON-LD、XML、クローラ設定、外部リソース読み込み、禁止拡張子、
定義段落、免責、図の `alt` を確認します。
